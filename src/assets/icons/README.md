# Portfolio icons

`translate.svg` is the Phosphor Icons `Translate` icon in regular weight,
exported from the installed `@phosphor-icons/react` package (MIT license).
It is kept as an SVG asset so the language button can apply a solid theme-aware fill (white in dark mode)
through the existing CSS mask.

`translate-medium.svg` adds a 4-unit rounded stroke to the same 256-unit outline
for light mode only (0.375 px at 24 px). The theme icon uses the same subtle
stroke increase; dark mode keeps the original regular weight.
